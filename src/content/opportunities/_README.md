# opportunities

Thesis, student-project and internship proposals. One Markdown file per proposal; the
file name is the URL (`digital-twin-maintenance.md` → `/opportunities/digital-twin-maintenance/`).
Files starting with an underscore (like this one) are ignored by the site.

`areas:` lists research topic ids from `src/data/research.yaml` and `supervisors:` lists
people slugs, so both are checked at build time. See docs/opportunities.md for the full
field reference, the valid values and worked examples.

The directory is empty on purpose: no proposal has been approved for publication yet.
